# V2 工作台首页

## 最新视觉基线

按最新首页草图实现黑白灰配色：浅灰背景（#F7F7F7）、白色卡片、深灰文字（#242526）和操作色（#343536），导航选中底色为中性浅灰。240px 侧栏、最大 1280px 内容区；1200px 以下侧栏收为 88px，600px 以下使用抽屉。问候语按本机时段变化，未认证时不虚构姓名或机构。Logo 使用用户提供的无字图案，右侧以独立文字显示 Mdis，不附加副标题；收起侧栏时仅显示图案。床号与姓名统一使用 20px / 28px、600 字重，中间细竖线分隔。

页头包含问候语、搜索、设备状态图标和账户入口，独立于列表限宽容器，铺满工作区并保留 36px 左右边距（窄屏 20px）；任务区域继续居中且最大宽度 1280px。设备未连接时显示带叉标识的图标，悬停、辅助阅读或点击可获取文字状态；不再占据单独卡片。默认未连接；连接本地测试设备后可展示该软件设备的连接状态，不代表物理分药机已连接。

今日摆药仅显示待摆药、已完成两个首页分类（9 / 3 个虚构任务），不代表修改底层 Session 状态机。双列独立白色患者卡片突出床号、姓名、头像区域、七天日期范围及药物数量；可用内容宽度不足 860px 或大字号时改为单列。圆形箭头进入患者核对入口，不触发分药。照片未提供时显示中性人像占位；不得用示意照片冒充患者身份。

每页最多六位患者。搜索在当前状态的全部患者中执行，搜索或切换状态重置页码；页脚统计为当前筛选结果，首尾页禁用越界按钮。

## Windows 字体规范

英文、数字 Segoe UI Variable；简体中文 Microsoft YaHei UI；等宽 Cascadia Mono。Windows 启动时读取本机 Fonts 目录；雅黑常规与粗体集合按字体内部族名选择 Microsoft YaHei UI，再显式注册到 Flutter，避免默认选到集合首个 Microsoft YaHei 字体。字体只在内存中选择，不修改系统字体或复制进仓库。侧栏导航统一使用 Card title（16 / 24、600），提示正文使用 Body。非 Windows 或缺少字体时使用平台回退字体。

| 样式 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| Display | 32 / 40 | 600 |
| Page title | 24 / 32 | 600 |
| Section title | 20 / 28 | 600 |
| Card title | 16 / 24 | 600 |
| Body strong | 14 / 20 | 600 |
| Body | 14 / 20 | 400 |
| Label | 12 / 16 | 600 |
| Caption | 12 / 16 | 400 |

最小 12px，默认 14px / 400，字距 0，默认左对齐；英文使用句首大写。字体定义集中于 `MdisType`，背景和颜色集中于 `MdisColors`。

## 实现范围

首页已连接本地内存状态和全部一级导航。患者卡片进入患者详情；执行任务会更新首页数量与进度。患者、处方、药盒、摆药、补药、记录、设置和账户页面的覆盖与限制见 [客户端 UI 清单](client-ui.md)。数据均为虚构开发资料，重启恢复初始状态；没有后端、真实硬件或持久化。
