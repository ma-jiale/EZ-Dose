# 本地任务与离线同步（待实现契约）

开始任务前，下载并校验完整患者/处方快照、日期分配、设备能力和本地授权。
断网只允许继续已经准备好的本地 Session；不把“任意离线新建任务”视为已支持能力。
本地事务同时写入执行状态、不可变事件与 Outbox。机器动作前持久化意图，收到反馈后持久化结果。
断电可能发生在机器动作与结果落盘之间；恢复时若结果不明确，要求核对实际药盒和设备，不重放下药命令。

Outbox 每个事件有稳定 event_id、tenant、device、session、step、序号、payload_version 和发生时间。
服务端以 (tenant_id, event_id) 唯一约束去重，并校验相同 ID 的内容一致；确认后客户端才标记 synced。
传输至少一次、服务端幂等。退避重试支持上限、抖动和可见错误，权限失效不能当作暂时断网无限重试。
并发修改用版本检查；旧处方快照不得静默覆盖新处方。设备与操作者授权、离线有效期需要产品确认。

同步状态与 Session 业务状态分开；completed + pending_sync 是合法组合。
隔离测试覆盖断网、崩溃、重复 ACK、重复上传、乱序、服务端超时、租户切换和处方冲突。
原 STM32 协议没有可证明的端到端幂等执行保证；不能宣称 exactly-once 摆药。
