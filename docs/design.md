# Design Principles & Design System

## Interaction Principles

- **现代大屏体验**：受 Apple Human Interface Guidelines 启发，面向 Windows 大屏电脑与 Android 平板打造专属护理工作台交互，不生搬硬套小屏移动端控件。
- **清晰层级与系统可见性**：
  - 一级导航固定为四项：**工作台**、**患者**、**记录**、**设置**。
  - 横屏（Landscape）优先设计，同时确保窄屏或窗口化时基本布局自适应可用。
  - 核心摆药流程中，患者身份、当前药物/投药数量、分药机物理状态和下一步操作指引始终处于显眼位置。
- **高确定性与容错机制**：
  - 暂停、跳过、待补药与已完成等关键状态必须附带清晰明确的文字说明，禁止仅靠颜色区分。
  - 硬件动作未得到明确确认前，前端禁止提前显示成功状态。
  - 关键操作二次确认需明确标注患者姓名、床号、药物名称、片数及物理动作意图。

## Design System Foundations

- **色彩规范（语义色）**：
  - `surface`：工作区背景与卡片容器背景，区分多级视觉层次。
  - `text`：标题色、正文色、辅助说明色。
  - `primary`：主流程引导色、核心确认动作。
  - `success` / `warning` / `danger`：执行完成、需人工干预、硬件故障与错误。
  - `offline`：网络离线指示色。
  - *注：所有警示与状态指示禁止单纯以颜色作为唯一识别依据。*
- **排版层次（Typography）**：
  - 优先级依次为：投入片数（字号最大、粗体最高视觉比重） > 当前药物名称 > 患者床号与姓名 > 页面标题 > 正文 > 辅助说明。
- **间距与网格（Spacing & Layout）**：
  - 采用 4pt / 8pt 基础栅格体系（4, 8, 12, 16, 24, 32, 48）。
  - 圆角统一：大容器（卡片、弹窗）与小控件（按钮、输入框、标签）形成比例规范。
- **动效规范（Motion）**：
  - 动效仅用于辅助操作连续性与状态感知，严格遵守系统减少动效（Reduce Motion）设置。

## Base Component Library

1. **Sidebar**：固定一级导航，支持展开/收起，集成当前租户与当前操作人状态。
2. **PatientCard**：患者信息卡，突出床号、姓名、待处理处方数与快捷进入入口。
3. **Button**：主要按钮、次要按钮、文字按钮、危险按钮，含正常/禁用/加载中/聚焦状态。
4. **StatusBadge**：状态徽标，统一展示任务状态、同步状态与硬件联机状态。
5. **MachineStatus**：分药机实时物理状态监控面板（托盘位置、电机状态、光耦读数、当前药盒识别状态）。
6. **ConfirmDialog & ErrorBanner**：高可靠交互对话框与全局/行内错误提示条。
